# Discord投稿用マニュアル（句会開設者向け）

最終更新: 2026-07-01

この文面は、句会の開設者・進行担当者に Discord へそのまま投稿する想定の短縮版です。

## 投稿 1/3: 句会を開く前に

```text
句会開設者向けミニマニュアル 1/3

まず決めること

1. 句会名
2. 兼題・説明
3. エントリー制にするか
4. エントリー締切、投句締切、選句締切
5. 1人あたりの投句数
6. 選句ルール（特選・並選など）
7. 作者を結果公開時に出すか、後から出すか、出さないか

対話式で作る場合は、次のコマンドを使います。

/kukai create

画面の案内に沿って設定してください。
作成後、Bot が句会チャンネルに案内と操作ボタンを投稿します。
```

## 投稿 2/3: 作成後に見るもの・進め方

```text
句会開設者向けミニマニュアル 2/3

作成後に確認するコマンド

/kukai info
句会名、兼題、状態、締切、投句数などを確認します。

/kukai status
参加者ごとのエントリー、投句、選句の進捗を確認します。

句会を次の段階へ進める場合

/kukai proceed

投句不足や選句不足がある場合、Bot が警告を出します。
内容を確認し、問題なければ「それでも進める」を選んでください。

参加者用ボタンを再投稿したい場合

/kukai button kind:current

現在の状態に合わせて、エントリー・投句・選句・結果のボタンを投稿します。
```

## 投稿 3/3: よく使う管理操作

```text
句会開設者向けミニマニュアル 3/3

エントリー承認が必要な句会

/entry approve
個別に承認します。

/entry reject
個別に却下します。

/entry approve-all
承認待ちをまとめて承認します。

設定を変更したい場合

/kukai edit

句会名、兼題、説明、締切、投句数、選句ルール、作者公開設定などを変更できます。
締切を変更した場合、通知スケジュールも再設定されます。

PDFを作る場合

/pdf submission
投句一覧PDFを作ります。

/pdf result
結果PDFを作ります。

通常は、PDFは実行した本人だけに見える返信で作成されます。
チャンネルに公開投稿したい場合は public:true を指定します。

/pdf submission public:true
/pdf result public:true

public:true で投稿できるのは句会管理者のみです。
PDFが大きすぎる場合は、ファイル添付ではなく一時URLで案内されます。

困ったときは、まず /kukai info と /kukai status を確認してください。
同じチャンネルに進行中の句会が複数ある場合は、コマンドに句会IDを指定してください。
```
