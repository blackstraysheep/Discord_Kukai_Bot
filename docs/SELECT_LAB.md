# 選句UI比較Lab

`/select-lab` は、選句操作の比較テスト用UIです。既存の `/select` と `/select-bulk` はそのまま利用できます。

## 重要

- Labはプレビューではありません。既存の選句と同じデータを読み書きします。
- Labで登録・変更・取消した内容は、既存の `/select` と他のLab画面にも反映されます。
- 操作できるのは選句受付中だけです。参加資格、自句制限、選句数上限、選評必須などのルールも通常どおり適用されます。
- 画面は実行者だけに表示され、10分で操作期限が切れます。期限切れ後はコマンドをもう一度実行してください。

## 3つの方式

### `/select-lab review [kukai_id]`

1句ずつ読みながら選ぶ方式です。選句種別を押すと即時保存し、次の未処理句へ進みます。任意の選評は「直前の句に選評」または選評編集メニューから追加します。選評必須の種別と作者コメントでは、保存前に入力画面が開きます。

### `/select-lab batch [kukai_id]`

選句種別を先に決め、該当する句を複数選ぶ方式です。1ページは最大25句です。複数選択メニューの送信時に、そのページのチェック状態が保存されます。選評必須の種別は一括登録せず、1句ずつ選評を入力します。

### `/select-lab form [kukai_id]`

現在の選句全体を、投句編集に近いフォームで置き換える方式です。

```text
選句:
特選=3
並選=1,4,8

選評:
3=景が鮮やかです

作者コメント:
10=春の朝を詠みました
```

欄から削除した内容は、フォーム送信時に選句データからも削除されます。選評内の改行は `\n` と表示され、そのまま保存すると元の改行へ戻ります。入力に誤りがある場合は全体を保存せず、既存データを維持します。

## 比較時の観点

- 選句完了までの操作数
- 句と現在の選句状態の読み取りやすさ
- 選評を追加・修正する際の迷いにくさ
- スマートフォンとデスクトップでの使いやすさ
- 25句を超える句会での移動しやすさ
